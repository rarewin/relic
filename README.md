# Relic (レリック)

[![Rust](https://img.shields.io/badge/language-Rust-orange.svg)](https://www.rust-lang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Relic** は、Rust で開発された軽量・高速な Emacs ライクの TUI（ターミナル）テキストエディタです。
快適なキーバインド操作とモダンな組み込みスクリプト言語 **Rhai** による拡張性を備えています。

---

## ✨ 主な特徴

- ⚡ **Rope データ構造による軽快な編集**: 大規模ファイルでも安定した高速テキスト編集を実現（[`ropey`](https://crates.io/crates/ropey) 採用）。
- ⌨️ **Emacs 互換の操作体系**: 基本移動、インクリメンタル検索（`C-s` / `C-r`）、キルリング（カット＆ペースト）、マーク＆リージョン選択、複数行 `C-k` 結合を完全サポート。
- 📜 **Rhai スクリプトによるカスタマイズ**: Kotlin / Swift ライクな構文を持つ Rhai スクリプト（`~/.config/relic/init.rhai`）でエディタの初期化やカスタム関数の作成が可能。
- 💡 **`M-x` による動的スクリプト実行**: ミニバッファから Rhai の式やカスタム関数をリアルタイムに評価・実行。
- 🎨 **構文ハイライト**: Rust, C/C++, Markdown などのシンタックスハイライトに対応。
- 📁 **スマートなミニバッファ補完**: `Find file`（`C-x C-f`）や `Save As`（`C-x C-w`）での Tab / Shift-Tab によるファイルパス順繰り補完。
- ↩️ **無制限の Undo / Redo**: 編集履歴とカーソル位置をスマートに復元（`C-/`, `M-_`）。

## ⌨️ キーバインド一覧

### カーソル移動
| キー | コマンド | 説明 |
| :--- | :--- | :--- |
| **`C-p`** / `Up` | `previous-line` | 1行上へ移動 |
| **`C-n`** / `Down` | `next-line` | 1行下へ移動 |
| **`C-b`** / `Left` | `backward-char` | 1文字左へ移動 |
| **`C-f`** / `Right` | `forward-char` | 1文字右へ移動 |
| **`C-a`** / `Home` | `move-beginning-of-line` | 行頭へ移動 |
| **`C-e`** / `End` | `move-end-of-line` | 行末へ移動 |
| **`C-v`** / `PageDown` | `scroll-up-command` | 1画面分下へスクロール |
| **`M-v`** (`Alt+v` / `Esc v`) / `PageUp` | `scroll-down-command` | 1画面分上へスクロール |

### 検索（Incremental Search）
| キー | コマンド | 説明 |
| :--- | :--- | :--- |
| **`C-s`** | `isearch-forward` | 前方インクリメンタル検索（検索中に再度 `C-s` で次の候補へ移動、空入力時は前回クエリを再利用） |
| **`C-r`** | `isearch-backward` | 後方インクリメンタル検索（検索中に再度 `C-r` で前の候補へ移動、空入力時は前回クエリを再利用） |
| **`Enter`** (検索中) | `isearch-exit` | 現在のマッチ位置にカーソルを置いて検索を確定 |
| **`C-g`** / `Esc` (検索中) | `isearch-abort` | 検索をキャンセルし、検索開始前のカーソル位置へ戻る |

### 編集・カット＆ペースト（Kill Ring）
| キー | コマンド | 説明 |
| :--- | :--- | :--- |
| **`C-d`** / `Delete` | `delete-char` | カーソル位置の文字を削除 |
| **`C-h`** / `Backspace` | `delete-backward-char` | カーソル直前の文字を削除 |
| **`C-k`** | `kill-line` | 行末まで（または改行）をカットしキルリングに保存（連続実行で結合） |
| **`C-SPC`** / `C-@` | `set-mark-command` | マークを設定／解除（範囲選択ハイライト開始） |
| **`M-w`** (`Alt+w` / `Esc w`) | `kill-ring-save` | 選択範囲をコピーしてキルリングに保存 |
| **`C-w`** | `kill-region` | 選択範囲をカットしてキルリングに保存 |
| **`C-y`** | `yank` | キルリング内の最新テキストをペースト |

### Undo / Redo
| キー | コマンド | 説明 |
| :--- | :--- | :--- |
| **`C-/`** / `C-_` / `C-x u` | `undo` | 直前の編集を取り消す（※WSL+SSH経由の `0x1F` / `C-7` にも対応） |
| **`M-_`** (`Alt+_` / `Esc _`) | `redo` | 取り消した編集を再実行 |

### ファイル操作・終了・拡張コマンド
| キー | コマンド | 説明 |
| :--- | :--- | :--- |
| **`C-x C-f`** | `find-file` | ファイルを開く（パス補完対応） |
| **`C-x C-s`** | `save-buffer` | 現在のファイルを上書き保存 |
| **`C-x C-w`** | `write-file` | 別名で保存（上書き確認あり） |
| **`C-x C-c`** | `save-buffers-kill-terminal` | エディタを終了（未保存時は確認プロンプト） |
| **`M-x`** (`Alt+x` / `Esc x`) | `eval-rhai` | Rhai スクリプト式・カスタム関数の評価・実行 |
| **`C-g`** (`Esc`) | `keyboard-quit` | 操作・マーク・プロンプトのキャンセル |

## 📜 Rhai スクリプトによるカスタマイズ

Relic は起動時に **`~/.config/relic/init.rhai`** が存在する場合、自動的に読み込んで評価します。
リポジトリ内の [`examples/init.rhai`](examples/init.rhai) をコピーして設定を開始できます。

```bash
# サンプル設定ファイルを配置する場合
mkdir -p ~/.config/relic
cp examples/init.rhai ~/.config/relic/init.rhai
```

### サンプルスクリプト ([`examples/init.rhai`](examples/init.rhai))

```rhai
// ============================================================
// Relic Editor Configuration Script (~/.config/relic/init.rhai)
// ============================================================

// 起動時の初期化フック
fn init() {
    let ver = version();
    set_message("✨ Relic v" + ver + " initialized with Rhai plugin engine!");
}

// ------------------------------------------------------------
// 設定例 1: スマートな行頭移動 (make C-a lovely)
// ------------------------------------------------------------
// Emacs の (if (looking-at "^") (back-to-indentation) (beginning-of-line)) と同等
fn lovely_beginning_of_line() {
    if looking_at("^") {
        back_to_indentation();
    } else {
        beginning_of_line();
    }
}

// C-a キーにカスタム関数をバインド
define_key("C-a", "lovely_beginning_of_line");

// ------------------------------------------------------------
// 設定例 2: カスタム関数
// ------------------------------------------------------------
fn insert_sample_header() {
    insert_text("// ----------------------------------------\n// Generated by Relic Custom Plugin\n// ----------------------------------------\n");
}

// 初期化実行
init();
```

### 利用可能なエディタ API

| カテゴリ | API 関数 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| **キーバインド** | `define_key(key, fn_name)` / `bind_key` | 指定キーシーケンスに Rhai 関数をバインド | `define_key("C-a", "lovely_bol");` |
| **状態判定** | `looking_at(pattern)` | カーソル位置のパターン一致判定（`"^"` は行頭、`"$"` は行末） | `if looking_at("^") { ... }` |
| | `is_bol()` | カーソルが真の行頭（列 0）にあるか | `if is_bol() { ... }` |
| | `is_at_indentation()` | カーソルがインデント先頭列にあるか | `if is_at_indentation() { ... }` |
| **カーソル情報** | `cursor_row()` / `cursor_col()` | 現在のカーソル行・列（0-indexed）を取得 | `let col = cursor_col();` |
| | `current_line()` / `line_len()` | 現在の行の文字列 / 行長を取得 | `let line = current_line();` |
| | `indentation_col()` | 現在の行のインデント位置（最初の非空白文字の列） | `let ind = indentation_col();` |
| **移動操作** | `beginning_of_line()` / `move_to_bol()` | 行頭（列 0）へ移動 | `beginning_of_line();` |
| | `back_to_indentation()` | 行のインデント先頭（最初の非空白文字）へ移動 | `back_to_indentation();` |
| | `end_of_line()` / `move_to_eol()` | 行末へ移動 | `end_of_line();` |
| | `move_cursor(row, col)` | カーソル位置を行・列（0-indexed）へ移動 | `move_cursor(0, 0);` |
| **編集・通知** | `insert_text(text)` | 現在のカーソル位置にテキストを挿入 | `insert_text("let x = 42;\n");` |
| | `set_message(msg)` | 最下行エコーエリアにメッセージを表示 | `set_message("Hello from Rhai!");` |
| | `version()` / `show_version()` | エディタのバージョン取得 / 表示 | `let v = version();` |

### `M-x` での動的実行例

`M-x`（または `Esc` → `x`）を押してミニバッファを開きます。

- **式の計算**: `1 + 2 * 3`  →  `=> 7`
- **バージョンの表示**: `show_version()`  →  `Relic Editor v0.1.0`
- **独自関数の実行**: `insert_sample_header()`  →  カーソル位置にヘッダーが挿入される

## 🚀 ビルド & 実行方法

### 動作要件
- Rust 1.85+ (Edition 2024)
- Cargo

### 起動
```bash
# 新規バッファで起動
cargo run

# 既存ファイル（または新規作成ファイル）を指定して起動
cargo run -- src/main.rs
```

### リリースビルド
```bash
cargo build --release
./target/release/relic [ファイルパス]
```

### テストの実行
```bash
cargo test
```
